# 捏捏猫 · 桌面宠物

照着我家橘猫画的果冻小猫，住在电脑桌面的右下角。

## 它会做什么

- **自己散步**：在任务栏（Mac 是程序坞）上方走来走去
- **拉脸**：揪住脸颊、鼻子、嘴巴、耳朵往外拉，松手会 Q 弹地弹回去
- **戳一下**：轻点它，会冒出爱心
- **拎起来**：按住它不动约半秒，就能把它拎到别的地方，松手它会掉下来
- **睡觉**：一分钟没人理它就会睡着，点一下就醒
- **右键点它**：可以让它别乱跑、去睡觉、回到右下角，或者退出

它不在任务栏里显示。要退出或者找回它，用右键菜单，或者点系统托盘（Mac 是右上角菜单栏）里的小猫图标。

## 下载安装

1. 打开仓库的 **Actions** 页面，点最新一次成功的“打包桌面宠物”
2. 在页面底部的 **Artifacts** 里下载：
   - Windows：`NieNieMiao-Windows`，解压后双击 `.exe` 就能运行，不用安装。如果弹出“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。
   - Mac：`NieNieMiao-macOS`，解压后打开对应的 `.dmg`（Apple 芯片选 `arm64`，Intel 芯片选 `x64`），把 NieNieMiao 拖进“应用程序”。
     第一次打开如果提示“已损坏”或“无法验证开发者”，打开“终端”运行下面这行，然后再打开：
     ```
     xattr -cr /Applications/NieNieMiao.app
     ```

## 自己运行源码

需要先装 [Node.js](https://nodejs.org)，然后：

```
cd desktop-pet
npm install
npm start
```
